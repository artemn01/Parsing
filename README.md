# Parsing
Скрипты на Python, собирающие данные с сайтов
# Файл Yandex_maps.py:
Файл Yandex_maps.py - Это Скрипт Для сбора данных Организаций с Яндекс Карт. Сайт использует Динамическую загрузку данных через JavaScript, что требует более сложный подход к написанию скрипта. 
Скрипт делится на этапы:
Первый этап - Сбор ссылок с карточек Организаций. Мы заходим на Яндекс карты через скрипт, Скрипт Имитирует реального пользователя, и листает сайт вниз, чтобы Данные загрузились и стали доступны для сбора ссылок. На этом этапе Используются библиотеки Selenium и SeleniumBase
Второй этап - Обработка собранных ссылок. На этом этапе наши собранные ссылки на Организации обрабатываются Асинхронно, через Asyncio и Curl_cffi. Наш Скрипт Заходит на эти ссылки и собирает оттуда нужную Информацию: Название, адрес, рейтинг и т.д. Использование Curl_cffi Позволяет имитировать TLS-отпечаток реального браузера, а asyncio значительно ускоряет процесс сбора информации благодаря асинхронности.
Далее все данные, собранные Скриптом, сохраняются в файл

В репозитории лежит полный датасет собранных данных этим скриптом в файле Yandex_maps_data.xlsx. Там лежит около 400 записей об Организациях

Проект был создан в конце января 2026 года в учебных целях. На момент создания  скрипт успешно собирал данные. Так как сайты постоянно меняют Свою структуру, на текущий момент может потребоваться обновление CSS-селекторов в Скрипте
